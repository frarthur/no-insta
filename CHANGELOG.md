# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Added
- Open directly on Instagram DM inbox.
- Native photo picker replacing the broken WebView file chooser.
- Native audio recorder replacing the broken WebView microphone.
- Feed and Reels pages blocked, redirected to profile.
- Home and Reels tabs hidden from the bottom navigation bar.
- Hardware back button navigates WebView history, then quits.
- Custom app icon via `flutter_launcher_icons`.
- Minimal permissions: Internet and Microphone only.
- Network security configuration limiting cleartext to Instagram domains.
